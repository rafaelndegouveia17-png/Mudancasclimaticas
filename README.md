# Mudancasclimaticas

## Aqui está a ideia do meu projeto:
##Selecionado:
> Podemos criar um site com o yolov8 para identificar o que é o lixo que o usuário mostra com a câmera e como descarta-lo
> O usuário entraria no site e ligaria a câmera logo em seguida ele aponta para um objeto como garrafa pet, latinha de alumínio, etc. logo em seguida o site irá usar o arquivo keras para indentificar qual é aquele objeto e retornará a lixeira que o objeto terá que ir e seu material.
> Descrição:
> podemos criar um site com o yolov8 para identificar o que é o lixo que o usuário mostra com a câmera e indicar como descartá-lo corretamente. A IA reconhece o objeto, classifica o material e exibe instruções de descarte, pontos de coleta próximos e dicas de reciclagem. Essa solução torna o recolhimento mais acessível, educativa e prática para qualquer pessoa.
